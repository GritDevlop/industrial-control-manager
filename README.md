# 工控资料聚合管理器

Windows 桌面端工控资料聚合管理工具，面向工控行业研发、调试、运维人员。

## 功能特性

### 📂 三级目录分类
- 按公司→类别→产品分类
- 按类别→公司→产品分类
- 一键切换分类模式
- 目录树折叠/展开

### 📦 产品展示
- 产品卡片纵向排列展示
- 点击卡片展开下拉列表
- 鼠标悬停显示产品参数
- 支持产品收藏功能

### 📁 资料管理
- 产品介绍、驱动软件、编程示例
- 支持自定义资料模块
- 本地文件关联
- 网络链接下载
- 文件批量关联

### 🔄 自动更新
- 开机自动检测/手动检测
- 更新频率设置
- 下载进度提示
- 断点续传支持

### ⚙️ 设置功能
- 浅色/深色主题切换
- 存储路径配置
- 导入/导出配置
- 数据备份与恢复

## 技术架构

- **前端框架**: Electron + HTML/CSS/JavaScript
- **数据存储**: JSON 配置文件 (electron-store)
- **日志系统**: electron-log
- **网络请求**: axios

## 使用说明

### 1. 设置存储路径
首次使用建议在设置中配置资料存储根目录，下载的文件将自动按"公司/类别/产品"分级存储。

### 2. 添加产品
点击左侧目录树的"+"按钮添加新产品，填写产品型号、名称、公司、类别等信息。

### 3. 关联资料
点击产品卡片下方的"添加资料"按钮，可选择关联本地文件或网络链接。

### 4. 收藏功能
点击产品卡片右上角的星标添加收藏，快速访问常用产品。

### 5. 数据备份
定期在设置中进行数据备份，支持一键恢复功能。
